# Code of conduct

Ottershelf follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project: in issues, pull requests, discussions, reviews
and any other project space, and when representing the project elsewhere.

In short: be respectful and considerate, welcome people of every background and level of
experience, give and accept constructive criticism graciously, and focus on what is best for the
project and its users. Harassment, personal attacks, discriminatory language and publishing
others' private information are not acceptable.

## Reporting

To report behaviour that violates this code of conduct, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature on the comment, issue or pull request concerned, or contact the maintainers privately
through the repository's [private vulnerability reporting](https://github.com/redmundmcmund/ottershelf/security/advisories/new)
form, stating that the report concerns the code of conduct. Reports are handled confidentially.

The maintainers may remove, edit or reject contributions that do not follow this code of conduct,
and may temporarily or permanently ban anyone whose behaviour they consider harmful, following the
enforcement guidelines of the Contributor Covenant.
