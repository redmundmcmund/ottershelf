# Content rating (IARC questionnaire): draft answers

Play Console: **App content > Content ratings > Start questionnaire**. The questionnaire's wording
changes from time to time; the answers below follow its structure. Answer for the content the app
itself contains and presents, not for what a user might keep on their own server.

## Context for the answers

- Ottershelf ships no books, images or other media. It displays content from the BookOrbit server
  the user signs in to: the user's own library, supplied by the user or the server's operator. In
  this respect it is a document viewer, like a PDF reader or file manager.
- It has no chat, messaging, comments, social feed or public profiles. It does not let users
  communicate with each other. (Several accounts on one server can see the same library, and a book
  request can be joined by another user of that server, but no messages are exchanged.)
- It has no ads, purchases, gambling, location sharing or general-purpose web browser. Links from
  book descriptions and "Open in Wikipedia" open in the user's own browser app.
- **Look up** shows short definitions from Wiktionary and summaries from Wikipedia for a word the
  user selected. This is third-party reference text, shown only on request.

## Target audience and content (separate section)

Play Console: **App content > Target audience and content**.

- Target age groups: **18 and over** (recommended). The app shows whatever the user's server holds
  and is meant for people who run or use a self-hosted library. Selecting any group under 13
  brings the app under the Families policy, which is not intended.
- Could the app unintentionally appeal to children? **No**: no characters, games or child-directed
  content beyond the otter artwork; the app requires sign-in to a user-operated server.

[If the maintainers prefer a wider audience, "13-15, 16-17, 18 and over" is also consistent with the
app; do not select an under-13 group.]
